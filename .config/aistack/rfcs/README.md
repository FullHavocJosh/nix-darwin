# RFCs

This is where aidev RFCs live, one file per RFC: `NNNN-slug.md`, numbered in order
(for example `0003-research-budget.md`).

Start from the template at [`../rfc-template.md`](../rfc-template.md) and follow its
"Process" and "When an RFC is required" sections. A draft does not gate anything;
only an `approved` or `implemented` RFC satisfies `rfc_check.py`.
